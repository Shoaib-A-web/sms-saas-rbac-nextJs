# 4. Authentication

I am using Auth.js / NextAuth with Credentials authentication.

Existing concepts:

```text
User
   ↓
Role
   ↓
Permissions
```

Roles:

```text
SUPER_ADMIN
SCHOOL_ADMIN
BRANCH_ADMIN
TEACHER
STAFF
```

There are two important identifier concepts:

```text
emp_id → employees/workers
std_id → students
```

The system must eventually support:

```text
Authentication
Authorization
RBAC
School scope
Branch scope
Permissions
```

Do not confuse authentication with authorization.

Authentication answers:

```text
Who is this user?
```

Authorization answers:

```text
What can this user do?
```

Scope answers:

```text
Which school's/branch's data can this user access?
```

# 6. Axios Requirement

From this point forward, for **client-side frontend API communication**, use **Axios**.

Do NOT use:

```javascript
fetch()
```

for normal frontend API calls.

Create a centralized Axios client.

Recommended structure:

```text
lib/
└── api/
    ├── axios.js
    ├── auth.js
    ├── students.js
    ├── teachers.js
    ├── schools.js
    ├── classes.js
    ├── sections.js
    └── ...
```

The Axios architecture should eventually look like:

```text
React page/component
        ↓
service function
        ↓
Axios instance
        ↓
Next.js API route
        ↓
business/service layer
        ↓
authorization
        ↓
Prisma
        ↓
MySQL
```

Do not put large API calls and business logic directly inside React pages.

# 17. Multi-Tenant Architecture

This is a SaaS application.

We need to carefully distinguish:

```text
SaaS platform
        ↓
School
        ↓
Branch
        ↓
Users
        ↓
Students / Teachers / Staff
```

A user's permissions are not enough.

For example:

```text
BRANCH_ADMIN
```

should not automatically mean:

```text
access every branch
```

We need both:

```text
role/permission
+
school/branch scope
```

Example:

```text
Can user:
student.update

AND

Does that student belong to a school/branch
the user is allowed to manage?
```

Every future API dealing with school data must consider this.
